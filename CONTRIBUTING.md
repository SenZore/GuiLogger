# Contributing

When reporting a bug, include your Minecraft, Fabric Loader, and Fabric API versions, what you were doing, and any useful error from `logs/latest.log`. Please remove player names, server addresses, and private chat before sharing a log.

Keep changes client-side. The `/logrecord` commands must stay local, and recordings should only contain information the client can see. Build with Java 25 using `gradlew.bat build` on Windows or `./gradlew build` on macOS or Linux. In a pull request, explain what changed and which checks you ran.
